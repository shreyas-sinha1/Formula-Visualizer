# Formula Visualizer

A minimal Next.js + Tailwind app for exploring a few mathematical formulas through interactive visual controls.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Included Views

- `(a+b)^2` area decomposition
- Sine graph
- Cosine graph
- Euler exponential graph
- Derivative tangent visual
- Integration area visual
